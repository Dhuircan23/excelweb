# ExcelWeb — MVP comercial

Cinco páginas HTML autónomas. Abren directamente en el navegador y funcionan en GitHub Pages sin build.

| Archivo | Página |
| --- | --- |
| index.html | Landing |
| demo.html | Demo interactiva Excel → app |
| diagnostico.html | Formulario de diagnóstico |
| dashboard.html | Dashboard conceptual |
| especificacion.html | Especificación para desarrollo |

Sistema de diseño: Modernist (`_ds/`). Tokens en `_ds/*/styles.css`.
